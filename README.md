# 또타미 (TOTA:ME) — 이용자 맞춤형 스마트 지하철 모빌리티 서비스

> **Your Personal Subway Companion**
> 출발 → 탑승 → 환승 → 역사 내부 이동 → 하차 → 목적지 → 이동 기록까지

React + TypeScript + Vite + Tailwind CSS 모바일 웹앱입니다. 스마트폰에서는 전체 화면 앱처럼, 데스크톱에서는 스마트폰 프레임 시연 모드로 동작합니다.

---

## 1. 메뉴 구조 (v4 — 하단 탭 6개)

| 하단 탭 | 역할 | 주요 기능 |
|---|---|---|
| **홈** | 출발 전 대시보드 + 경로 검색 | 출발·도착 검색 → 경로 비교(10가지 조건, 시간·환승·도보·혼잡·지연·출구·추천 이유), 스마트 출발 요약, 운행 정보, 주요 역 혼잡도, 최근·즐겨찾기, 주변 역, 외국인 모드, 광고 |
| **스마트 출발** | "지금 출발하면 탈 수 있을까?" | 일반 이동 / 이번 열차 꼭 탑승 모드, 현재 위치·저장 장소·역 출발, 역 입구→개찰구→승강장 시간 + 혼잡(예상) + 안전 여유, 4단계 안내 문구, 탑승 추천·다음 열차, 대체 경로, 열차 알림, 출발 → 지금 어디? |
| **지금 어디?** | 이동 중 내비게이션 | 미니 지도, 현재 역·다음 역, 진행률, 탑승 전 안내(스마트 출발 연결), 혼잡 칸, 환승 예정역(스마트 환승 연결), 장애 대응·대체 경로, 도착·출구 |
| **스마트 환승** | 환승 시간 숫자 비교 | 환승 열차 출발까지 남은 시간 / 통로 이동 예상 / 남는 시간 + 상태 문구, 하차·승강장 도착·연결 열차·다음 열차 시각표, 검증된(예시) 동선 데이터가 있을 때만 단계 안내 |
| **오늘 일정** | 약속 시간 역산 · 귀가 · 막차 | 약속 등록(장소·역·날짜·시간·도착 희망·출발지·경로 선호·여유·알림), 권장 출발 시간 계산 근거, 이동 중 도착 예정 재계산·지각 경고, 귀가 목표 시간·막차 역산, 통합 타임라인, 상태별 그룹 |
| **MY** | 계정·설정 | 이동 리포트, 알림 설정(다중·반복), 자주 가는 장소(기본 출발지·기본 귀가지), 즐겨찾는 경로·역, 언어, 프리미엄, 보행속도, 접근성, 개인정보 |

- 이전 주소 호환: `/route` → 홈의 경로 검색, `/report` → MY › 이동 리포트
- 탭 위에 열리는 화면: 이동 리포트 · 알림 설정 · 혼잡도 · 역사 내부 안내 · 외국인 모드 · 프리미엄
- 검색 경로·이동 중 상태·오늘 일정은 탭을 옮겨도 유지되고, 이동 중 상태와 일정은 새로고침 후에도 복원됩니다.

## 2. 기능 연결 흐름

```
홈 검색 ─▶ 경로 결과 ─(스마트 출발 카드)─▶ 스마트 출발 ─(출발)─▶ 지금 어디? ─(환승역)─▶ 스마트 환승
오늘 일정 ─(스마트 출발 / 약속 장소로 출발)─▶ 지금 어디? ─(도착)─▶ 귀가 알림 ─(귀가 출발)─▶ 지금 어디?
모든 이동 완료 ─▶ MY › 이동 리포트 (실제 기록만 집계)
```

### 권장 출발 시간 계산 (오늘 일정)
`권장 출발 = 도착 희망 시각 − (출발지→승강장 + 열차 대기·탑승·환승 + 지연 + 하차 후 출구→약속 장소) − 여유 시간`
예: `18:30 − 55분 − 10분 = 17:25` — 화면에 실제 검색된 경로 값으로 계산 근거를 그대로 보여줍니다.

### 귀가 · 막차
- 귀가 출발 = 목표 귀가 시각 − (약속 장소→역 + 지하철 + 집 근처 역→집) − 여유
- 막차 기준 출발 마감 = 각 구간 탑승역 막차(예상) − 그 역까지 걸리는 시간 중 가장 이른 값. 목표보다 막차가 더 빠듯하면 막차 기준으로 안내합니다.
- 막차 시각은 공식 시간표 미연동으로 **예상값(23:50 기준)** 이며 화면에 "예상"으로 표시됩니다.

## 2-1. 알림 (다중 · 반복)

| 기능 | 알림 시점 (여러 개 선택) | 반복 · 중단 조건 |
|---|---|---|
| 약속 출발 | 권장 출발 30/15/0분 전 (+60·45·20·10·5) · 지연 재계산 · 지각 경고 | 미출발 시 n분마다 n회 · 출발/도착/취소/삭제/알림 끄기 시 중단 |
| 열차 탑승 | 출발 준비 · 출발 시점 · 탑승 어려워지는 시점 | 이동 시작 또는 알림 끄기 시 중단 (반복 시 다음 열차로 재계산) |
| 환승 | n정거장 전 · 하차 · 방향 · 통로 · 시간 부족 | 다음 역 이동 / 환승 완료 시 중단 |
| 하차 | n정거장 전 · 도착 · 추가 알림 | 이동 종료 시 중단 |
| 귀가 | 귀가 출발 30/15/0분 전 | 미출발 재알림 · 귀가 출발/도착/취소 시 중단 |
| 막차 | 출발 마감 n분 전 · 임박 · 탑승 어려움 | 귀가 출발 시 중단 |

- 일정 변경 시 자동 재예약, 삭제 시 자동 취소, 발송 기록으로 중복 방지, **MY › 알림 설정**에서 예약 목록·발송 기록(발송/미발송, 실제 사용된 출력 방식) 확인
- 테스트: "지금 테스트"(즉시) · "10초 뒤 예약 테스트"(실제 스케줄러 경로로 발송)

### 알림이 실제로 동작하는 환경
| 환경 | 동작 |
|---|---|
| 앱이 열려 있음 (Android Chrome · 데스크톱) | 정해진 시각에 인앱 배너 + 알림음 + 진동(Android) + 음성 + 시스템 알림(권한 허용 시) |
| 백그라운드 탭 | 브라우저 정책상 타이머가 지연될 수 있음 (보통 1분 이내) |
| iOS Safari | 홈 화면에 추가한 PWA(iOS 16.4+)에서만 시스템 알림 · 진동 미지원 |
| **앱을 완전히 닫음** | **예약 알림 미발송** — 다시 열면 놓친 알림은 한꺼번에 보내지 않고 "미발송"으로 기록 |

앱이 닫혀 있어도 알림을 받으려면 **서버 푸시가 필요**합니다: Web Push 구독(VAPID 키) 저장 → 일정·알림 시각을 DB에 저장 → 1분 주기 예약 작업(Supabase Edge Function + pg_cron 또는 Vercel Cron)에서 발송. 서비스 워커(`public/sw.js`)에는 `push` 수신 처리가 들어 있으나 **발송 서버는 이 저장소에 포함되어 있지 않습니다.** (`supabase/schema.sql`에 필요한 테이블 초안 포함)

## 3. 구현 현황 — 세 가지로 구분

### ① 실제 데이터 연동까지 완료
- **역·노선 536개 역** (1~9호선, 공항철도, 경의중앙, 수인분당, 신분당, 우이신설, 신림, 김포골드) — 좌표·4개 언어 역명·노선 연결 (OpenStreetMap)
- **요금 안내** — 서울시 교통요금(2025-06-28 시행): 교통카드 일반 1,550원 / 1회권 1,650원 / 청소년 900원 / 어린이 550원 / 조조 1,240원, 거리비례 운임 계산
- **기후동행카드 단기권** — 1일 5,000원 · 2일 8,000원 · 3일 10,000원 · 5일 15,000원 · 7일 20,000원 (서울시 안내)
- 다익스트라 기반 맞춤 경로 탐색(10가지 조건), 4개 언어 UI·역명, 위치 권한·동의, 알림(인앱·알림음·진동·음성·시스템 알림), 이동 기록 저장·삭제

### ② 화면·동작은 구현됐고 API 키 / 데이터 확보가 필요
| 기능 | 현재 상태 | 필요한 것 |
|---|---|---|
| 실시간 도착정보 | `api/arrival.ts` 완성 | `SEOUL_SUBWAY_API_KEY` |
| 열차 지연 계산 | 시뮬레이션 지연은 전체 기능과 연동. 실시간 정보가 없으면 "실시간 운행정보를 확인할 수 없어요"로 표시 (정상 운행이라고 단정하지 않음) | 실시간 API + 공식 시간표 데이터 |
| 역·칸별 혼잡도 | 시간대·역 특성 기반 **예상값** (화면에 "예상" 표시, % 미표시) | SK open API 등 실시간 혼잡도 (유료·일부 노선) |
| 역사 내부 내비게이션 | 길찾기 엔진·층별 지도·6가지 이동 방식·QR 위치 인식 완성. **이대역은 시연용 개략 도면** | 실제 역사 도면·시설 좌표 (서울교통공사) |
| 출구·첫차/막차·역 코드 | 이대역은 도면 출구, 그 외 예시 / 막차 예상(23:50 기준) | 공공데이터포털 출구·시간표 |
| 열차 시각 (스마트 출발·환승·일정) | 노선별 운행 간격 기반 **예상 시각표** ("예상" 표시) | 서울교통공사 열차 시간표 API |
| 환승 동선 | 일부 역 예시 데이터만 단계 안내, 나머지는 방향·거리를 만들지 않고 "동선 데이터 없음" 표시 | 역별 환승 동선(서울교통공사) |
| 앱 종료 상태 예약 알림 | 서비스 워커 `push` 수신 준비 | VAPID 키 + 푸시 발송 서버 + 예약 작업 |
| 카메라 번역 | 촬영·업로드·서버 함수(`api/translate.ts`) 완성 + 오프라인 표지판 사전 | `GOOGLE_CLOUD_API_KEY` (Vision + Translation) |
| 프리미엄 결제 | 토스페이먼츠 결제창 → 서버 승인(`api/payments/confirm.ts`) 후에만 구독 활성화. 키가 없으면 결제 버튼 비활성 | `VITE_TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY` (테스트 키로 테스트 결제) / 정기결제는 빌링 계약 |
| 회원가입·로그인 | Supabase Auth REST 연동 코드 완성 | `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` + `supabase/schema.sql` |
| 광고 | 하우스 광고(가상 업체) 5개 영역, 프리미엄 시 제거, 이동 안내 화면 미삽입 | Google AdSense 승인 |

### ③ 네이티브 앱 또는 별도 하드웨어 필요
- 화면이 꺼진 상태의 백그라운드 위치 추적 (예약 알림은 서버 푸시로 가능)
- Wi-Fi·BLE 비콘 실내 측위 (웹은 QR·직접 선택으로 대체)
- 정확한 이어폰 연결 감지, Apple Watch·Galaxy Watch 전용 화면·햅틱, iPhone 진동

> 시연 편의를 위해 마이페이지 › 프리미엄에 **"프리미엄 기능 미리보기 (결제 아님)"** 토글이 있습니다. 결제나 구독 상태로 기록되지 않습니다.

## 6. GitHub 업로드 · Vercel 배포

```bash
git add .
git commit -m "또타미 v4"
git push
```

GitHub 웹에서 올릴 때는 **압축을 푼 폴더 안의 항목 전체**(`src`, `public`, `api`, `scripts`, `supabase` 포함)를 한 번에 드래그하세요. Vercel은 Framework **Vite**, Output `dist`로 자동 인식되며 `/api/*` 서버리스 함수도 함께 배포됩니다. `/depart`, `/move`, `/transfer`, `/today`, `/my`, `/route`, `/report`, `/pay/success` 새로고침 시 404가 나지 않습니다.

## 7. 프로젝트 구조

```
├─ api/                       # Vercel 서버리스 (실시간 도착, 번역, 결제 승인)
├─ supabase/schema.sql        # trips 테이블 (+ delay_min) · 푸시 구독/일정 테이블 초안
├─ scripts/                   # 역 데이터 생성 (OSM 원본)
├─ public/                    # 파비콘, 매니페스트, 서비스 워커
└─ src/
   ├─ data/      network.ts(노선·역) · indoor.ts(실내 도면) · foreign.ts(요금·관광·긴급)
   ├─ lib/       routing(경로) · boarding(스마트 출발·환승 타임라인) · schedule(약속·귀가·막차 역산)
   │             alarms(다중·반복 알림 스케줄러) · indoor(실내 길찾기) · congestion · notify · geo
   ├─ services/  delay(운행 상태) · trips(기록) · auth(회원) · premium(결제) · maps · ads · realtime
   ├─ i18n/      messages.ts + messages-v3.ts + messages-v4.ts (한/영/중/일)
   ├─ state/     store.tsx · plans.ts(일정 계산) · useNow.ts
   ├─ components/
   └─ screens/   Home(+Route) · DepartureScreen(스마트 출발) · Move(지금 어디?) · TransferScreen(스마트 환승)
                 TodayScreen · ApptEditor(오늘 일정) · My · ReportScreen · AlarmSettings
                 CongestionScreen · IndoorNav · ForeignMode · PremiumScreen
```
